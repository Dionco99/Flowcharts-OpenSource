# Desk

Stage-1 replay desk. One symbol, one cursor, up to four panes. The shell composes `packages/bars`, `packages/replay`, `packages/orders`, `packages/chart-tools`, and `packages/workspace`.

This directory is a scaffold. A live broker connection is outside this app.

See the repository [README](../../README.md) and [docs/dependencies.md](../../docs/dependencies.md).
