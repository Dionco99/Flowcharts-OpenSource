# Apps

A shell a person opens lives here. Libraries live in [`packages/`](../packages).

| App | Role |
| --- | --- |
| [`desk`](desk) | Stage-1 replay desk. It composes bars, replay, orders, chart-tools, and workspace. |
| [`web`](web) | Self-hosted static shell. It does not open a broker or read a tape. See [docs/deploy.md](../docs/deploy.md). |
