# orders

The strategy-facing broker port: place, modify, cancel, close, modify protection, and snapshot. One port is one symbol and one net position. The replay fill adapter is the stage-1 matcher. Orders, fills, and the position are plain records. This package does not import a broker SDK.

This directory is a scaffold.

See the repository [README](../../README.md) and [docs/dependencies.md](../../docs/dependencies.md).
