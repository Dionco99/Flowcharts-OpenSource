# Packages

Libraries live here. Shells live in [`apps/`](../apps).

| Package | Owns |
| --- | --- |
| [`bars`](bars) | Symbol spec, 1-minute tape, and higher-timeframe windows. |
| [`orders`](orders) | Broker port, orders, fills, and the net position. |
| [`brokers`](brokers) | Venue adapters behind the broker port. |
| [`plugins`](plugins) | Indicator and strategy registration. |
| [`script`](script) | Flowchart Script. |
| [`replay`](replay) | Replay clock and the session file. |
| [`risk`](risk) | Position size, R, and later account risk checks. |
| [`journal`](journal) | Local trade log. |
| [`edge`](edge) | Expectancy from journal records. |
| [`chart-tools`](chart-tools) | Drawings, chart types, and shipped studies. |
| [`workspace`](workspace) | Panes, layouts, and crosshair sync. |
| [`multi-instrument`](multi-instrument) | A second symbol, compare, and ratio. |
| [`alerts`](alerts) | Alert rules, the local log, the screener, and watchlists. |
