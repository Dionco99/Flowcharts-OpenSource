# Security

## Reporting a vulnerability

Report a vulnerability through GitHub Security Advisories:

https://github.com/Dionco99/Flowcharts-OpenSource/security/advisories/new

A public issue is the wrong place for a security report. Include the package path and enough detail to reproduce the problem.

## What is in scope

This repository is the public scaffold. There is no hosted service and no account system yet.

When adapters land, API keys, tokens, passphrases, and account identifiers are secrets. They stay out of commits, issues, logs, and screenshots.

A live-money order path stays behind an explicit confirmation. A report that a default setting can send a live order is in scope.

## Supported versions

Fixes land on `main`. There are no release branches yet.
